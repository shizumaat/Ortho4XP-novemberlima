Main window · toggle platform and appearance above — note the global menu bar on macOS vs. the in-window menu on Windows/Linux.

M1
“Pick on map” is the primary path to choosing a tile; lat/lon become validated spinboxes (−85…84 / −180…179) instead of free-text fields checked only at build time. Q: keep manual entry this prominent, or tuck it behind the map picker entirely?
M2
Split-button menus replace hidden modifier-clicks. Shift-click = Sort mesh and Ctrl-click = Community mesh become visible menu items (shortcuts kept as accelerators). Same pattern on step 3 for “masks for imagery.” Q: any other hidden gestures you want surfaced here?
M3
Numbered steps teach the 1→4 pipeline order; “All in one” becomes an accented Build all default button. Q: are the shortened step names acceptable?
M4
Labeled progress bars with percentages, mapped to the three existing bar roles; overall progress mirrored in the Dock/taskbar icon. Q: keep three bars, or one overall bar + detail on hover?
M5
Log panel with level selector (maps to verbosity), filter, copy and save; timestamps and colored warnings. Replaces raw stdout capture visually — the queue mechanism underneath is unchanged.
M6
Stop is two-state: disabled when idle, and shows “Stopping after current step…” once pressed, since red_flag is polled. Q: should Stop also offer a hard-cancel after a timeout?

T1
Mode toolbar replaces modifier chords. Pan / Select / Multi-select are explicit modes with cursor changes; old shortcuts stay as accelerators. Also fixes the macOS button-2/3 remapping problem for trackpads. Q: should double-click-to-set-active survive in every mode?

T4
Live status bar: cursor coordinates, zoom, selection and build counts. The map itself gains wheel/pinch zoom (QGraphicsView), replacing the fixed ZL-6 image pan.
T5
Per-tile context menu replaces Ctrl-click (symlink toggle) and the o key (overlays link moves to Tools menu). Q: anything else that belongs on this menu — e.g. “Open tile folder”?
